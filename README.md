# Midnight Xotixs

A dual-themed web application featuring an artisanal bakery front (*Midnight Treats*) with an authentic single-use invitation gateway leading to the *Midnight Xotixs* restricted chamber and embedded Sanity V3 Studio admin panel.

## Features
- **Bakery Decoy UI**: Clean, responsive, artisanal bakery storefront.
- **Gatekeeper Modal**: Decoy Sign In and single-use passcode gateway.
- **Sanity.io Integration**: Live GROQ query validation and atomic document mutation (`isUsed: true`).
- **Midnight Xotixs Chamber**: Cyber streetwear storefront with three product divisions: Nick, Pens, and Treats.
- **Sanity V3 Studio**: Admin panel accessible via `/studio` to manage passcodes and inventory.
